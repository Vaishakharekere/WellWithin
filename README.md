# WellWithin 🌱  
**A Holistic Mental Wellness Companion**

WellWithin is a modern, user-centric wellness platform built to help users track their emotions, manage stress, and build better mental health habits. With features like emotion-based journaling, personalized music recommendations, and insightful dashboards, WellWithin brings mental well-being to the forefront through tech.

---

## ✨ Features

- 🧠 Emotion Detection via Text & Audio
- 🎵 Emotion-Aware Music Recommendation
- 📓 Daily Mood Tracking & Journaling
- 📊 Real-Time Analytics Dashboard (Streamlit)
- 🔐 User Authentication & Secure Profiles
- 🌐 Mobile-Responsive & Modern UI

---

## 🛠️ Tech Stack

| Layer        | Technology                     |
|--------------|--------------------------------|
| Frontend     | React.js, Tailwind CSS         |
| Backend      | Node.js, Express.js, Flask     |
| Emotion AI   | DeepFace, HuggingFace, Librosa |
| Auth & DB    | Firebase / Supabase / MongoDB  |
| Dashboard    | Streamlit                      |
| Deployment   | Vercel, Render, Heroku (if used) |
